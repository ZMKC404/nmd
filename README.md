# Nothing MD

**Nothing but Markdown.**

<br>

凌晨两点。

你打开通义听悟网页版，第四十七次拖拽视频。
浏览器标签页开了十二个。
赠送的转录时长还剩 800 分钟。

而你只想把昨天那个 20 分钟的分享会，
变成一段能搜索的文字。

<br>

视频是信息的坟墓。
你收藏了，你焦虑了，
你从未真正拥有过里面的知识。

一段 Markdown。
可搜索，可编辑，可拼接，可丢弃。
知识终于属于你了。

<br>

你只用说一句话：

「把那个课程变成我的笔记。」

剩下的，交给 Agent。

<br>

```bash
curl -fsSL https://raw.githubusercontent.com/ZMKC404/nmd/main/install.sh | bash
```

<br>

如果你也有一个文件夹，叫「稍后看」，
里面躺着 100 个从未打开的视频——

现在，可以让 Agent 帮你把它们，
一个一个，变成文字了。

<br>

**Nothing but Markdown.**
