# 索引合并提示词（S6-2：条目 → 场景索引）

把所有索引条目（{{条目目录}}）合并成一份场景索引，写入 {{输出文件路径}}。

## 索引结构

1. **使用说明**（3 行）：先按场景反查文件名，再读精华稿，需要细节查精校稿
2. **实战场景反查**（主体）：把全部条目按一线真实问题聚类为 12-18 个场景；每条格式：
   `- 「场景问法」→ \`文件名\`（一句话说明）`
   一篇可属多个场景
3. **体系正查**（附录一）：按章节/分卷列出全部文件及一句话
4. **术语表**（附录二）：核心术语 → 出处文件

## 硬规则
- 覆盖全部条目，一个不落；文件名与磁盘文件名完全一致（不含扩展名）
- 写完用脚本比对磁盘文件列表自查覆盖率

完成后回复一行：索引完成，覆盖 N 个文件，M 个场景。
